perangkat lunak pihak ketiga di bawah ini; setiap komponen tetap
berada di bawah lisensinya sendiri.

----------------------------------------------------------------------
1. FFmpeg  -  GNU General Public License v3 atau lebih baru
----------------------------------------------------------------------

FFmpeg TIDAK termasuk dalam kode sumber Zerofuss dan tidak berada di
repositori ini. Zerofuss menjalankannya sebagai proses terpisah dan
berkomunikasi dengannya hanya lewat pipe stdin/stdout - tidak ada
penautan kode. Pemakai mengunduhnya sendiri (ZEROFUSS_FFMPEG atau
PATH); ambil-ffmpeg-mac.sh mengunduhnya untuk build macOS.

Build yang disarankan memakai konfigurasi --enable-gpl
--enable-version3 --enable-libx264, sehingga berlaku GPL v3. Siapa
pun yang membungkus ffmpeg ke dalam installer atau .app dan
membagikannya wajib memenuhi kewajiban GPL v3 untuk binary itu.

Hak cipta (C) 2000-2026 para pengembang FFmpeg.
  Beranda proyek : https://ffmpeg.org
  Kode sumber    : https://ffmpeg.org/download.html
  Teks GPL v3    : https://www.gnu.org/licenses/gpl-3.0.txt

Sumber build yang dikenal baik:

  Windows  gyan.dev, https://www.gyan.dev/ffmpeg/builds/
  macOS    build server FFmpeg milik Martin Riedl, dipakai oleh
           ambil-ffmpeg-mac.sh - https://ffmpeg.martin-riedl.de/
           skrip build lengkap:
           https://git.martin-riedl.de/ffmpeg/build-script

----------------------------------------------------------------------
2. Mesin tampilan sistem: WebView2 dan WKWebView
----------------------------------------------------------------------

Zerofuss memakai mesin tampilan milik sistem operasi, dan tidak
mendistribusikan ulang keduanya:

  Windows  Microsoft Edge WebView2, disediakan oleh Windows
           https://developer.microsoft.com/microsoft-edge/webview2/
  macOS    WKWebView (WebKit), bagian dari macOS
           https://webkit.org - LGPL-2.1 dan BSD-2-Clause
